# The Cardinal's Promise — Social Media System

This is the operating system for putting the Cardinal's Promise mission in
front of the people who need it: families in a caregiving crisis, people
sitting at a bedside tonight, providers who make the hospice call.

The book is the vehicle. The mission is presence. Every post either gives
someone language, gives someone permission, or gives someone a map. If a
post does none of those three things, it doesn't go out.

## What's in this folder

| File | What it is |
|---|---|
| `content-pillars.md` | The five pillars every post comes from |
| `platform-playbooks.md` | How each platform is used (Facebook, Instagram, LinkedIn, X/Threads, TikTok/Shorts, YouTube) |
| `reddit-playbook.md` | The Reddit system — give-first, subreddit map, rules of engagement |
| `content-library.md` | Four weeks of ready-to-post content, with platform variants |
| `post-tracker.csv` | Log of what went out, where, and what it did |

## The weekly rhythm

Fifteen to forty-five minutes a day. Sustainable beats impressive.

| Day | Action |
|---|---|
| Monday | **The Map** — one practical caregiver post (from the Toolkit). All platforms. |
| Tuesday | Reddit: 15 minutes answering questions. No links. Just help. |
| Wednesday | **The Unspoken Words** — one bedside script or permission phrase. All platforms. |
| Thursday | Reddit: 15 minutes. Same rule. |
| Friday | **The Story** — one true moment. Lou, the mat, the window, the work. All platforms. |
| Saturday | Engage: reply to every comment from the week. Every one. |
| Sunday | Off. Presence starts at home. |

## The rules (non-negotiable)

1. **Never perform grief.** Witness it. If a post feels like it's selling
   Lou's death, kill it.
2. **One moment, one truth, one action.** Every post. No listicles of
   feelings.
3. **Reply to everyone.** A comment from a stranded caregiver at 2am is the
   whole point. The post is the door; the reply is the room.
4. **The book is mentioned, not pushed.** Link in bio, link on the site,
   mention when asked. The content has to be worth something on its own.
5. **Reddit is different.** Read `reddit-playbook.md` before posting
   anything there. Plugging gets banned — and worse, it breaks trust with
   the exact people this mission exists for.

## How to use the content library

Open `content-library.md`. Each entry has a base post plus platform notes.
Copy, adjust the day's details if something real happened, post, log it in
`post-tracker.csv`. When the four weeks run out, the pillars generate the
next four — the story doesn't run out because the work doesn't stop.
